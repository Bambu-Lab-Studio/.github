## Understanding Bambu Lab Studio Core Components

- **Plate** - The bed Bambu Lab Studio shows for this job.
- **Printer** - A machine you own or were given to run.
- **Preview** - What Bambu Studio draws before the job leaves the PC.
- **Project** - The Bambu Studios file you stored next to the model.
- **Profile** - Settings that match this printer, not a borrowed machine.
- **Queue** - One job you meant to send, not a pile of tests.
- **Note** - Why this plate differs from the last successful print.

## First Look at Bambu Lab Studio

Bambu Lab Studio is for a plate you build yourself: a model you may print, a printer you own, a preview you check. Bambu Studio holds the job. Bambu Studios is that same workspace the next day.

You load the part, you look at the plate, you send only when the preview matches what you meant. You stop when the file is stored.

It does not search the disk for random meshes. The live job is the one you named.

The plate you send should still match the preview you checked. If Bambu Studio shows a printer you do not run, stop and pick the machine on this desk. Bambu Studios is easier when the project sits next to the model.
